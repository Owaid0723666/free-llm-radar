# free-llm-radar

[中文](README.zh-CN.md)

Free LLM API tiers change every week: models appear, get renamed, start returning 429, or quietly stop being free. This repo asks every free model on a handful of providers one short question once a day and writes down which ones answered and how long they took. The table below is regenerated by a scheduled GitHub Action.

## What it tests

| Provider | Models | Free tier, in short |
| --- | --- | --- |
| [OpenRouter](https://openrouter.ai) | the 6 newest `:free` models from its model list | 50 free requests a day without $10 of credit |
| [Google Gemini API](https://ai.google.dev) | Flash and Flash-Lite | free tier through Google AI Studio; not for apps serving the EEA, Switzerland or the UK |
| [Mistral](https://mistral.ai) | the small models | free experiment plan with a monthly allowance |
| [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/) | 3 text models | 10,000 free neurons a day |
| [NVIDIA NIM](https://build.nvidia.com) | 4 models | free for prototyping and research |
| [Groq](https://groq.com) | up to 8 chat models from its model list | per-model daily limits (skipped here until a key is added) |
| [onomeo](https://onomeo.com) | 5 low-cost models | free credits by daily check-in, spent per character |

The exact model ids are in [providers.json](providers.json). Each question is `Reply with the single word: OK` with `max_tokens` 32. Nothing else is sent, and only pass/fail, the time taken and the HTTP status are kept.

## Run it yourself

Node 18 or newer, no install step. Set the keys you have; providers without a key are skipped.

```bash
git clone https://github.com/Owaid0723666/free-llm-radar
cd free-llm-radar
export GEMINI_API_KEY=...        # any of the keys below
node radar.mjs
```

| Variable | Where to get it |
| --- | --- |
| `OPENROUTER_API_KEY` | openrouter.ai/keys |
| `GEMINI_API_KEY` | aistudio.google.com/apikey |
| `MISTRAL_API_KEY` | console.mistral.ai/api-keys |
| `CLOUDFLARE_API_KEY` and `CLOUDFLARE_ACCOUNT_ID` | dash.cloudflare.com, a token with Workers AI read permission |
| `NVIDIA_API_KEY` | build.nvidia.com |
| `GROQ_API_KEY` | console.groq.com/keys |
| `ONOMEO_API_KEY` | onomeo.com/dashboard |

The run rewrites the table in both READMEs and writes `results/latest.json` and `results/history.json` (the last 14 runs per model).

## Add a provider

Any OpenAI-compatible endpoint works. Add an entry to `providers.json`:

```json
{
  "id": "example",
  "name": "Example AI",
  "site": "https://example.com",
  "base": "https://api.example.com/v1",
  "keyEnv": "EXAMPLE_API_KEY",
  "models": ["model-a", "model-b"]
}
```

Instead of `models`, `"discover": "free-suffix"` reads the provider's `/models` list and keeps ids ending in `:free`, and `"discover": "all"` keeps everything except ids containing a word in `skip`. `max` caps how many are asked (default 10). `${NAME}` in `base` is filled from the environment. Run `npm test` before opening a pull request.
